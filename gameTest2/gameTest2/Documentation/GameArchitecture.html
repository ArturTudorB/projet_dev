?? Game States

Main Menu State

  • Start Game
  • View Leaderboard
  • Quit Game
  • Music: Main Menu Theme

Username Input State

  • Text Input Field
  • Cursor Animation
  • Enter to Confirm
  • Backspace Support

Playing State

  • Active Gameplay
  • Entity Management
  • Collision Detection
  • Score Tracking

Game Over State

  • Final Score Display
  • Save to Database
  • Return to Menu
  • Play Again Option

Leaderboard State

  • Top 10 Scores
  • Player Names
  • Timestamps
  • Return Navigation

?? Game Flow

1. Initialization Phase

Game1() Constructor ? Create Graphics Manager ? Set Fullscreen

?

2. Initialize Systems

Initialize() ? Create Core Systems ? Setup Database

?

3. Load Content

LoadContent() ? Load Textures ? Load Audio ? Create Renderers

?

4. Main Game Loop

Update() + Draw() ? State Manager Delegation ? 60 FPS

?? Entity Types

Player

• HP: 3 (max)
• Shield: 0-3
• Speed: Dynamic
• Active Buffs
+ Move()
+ Shoot()
+ TakeDamage()

Enemy

• 4 Types
• AI Movement
• Shoot at Player
• Death Animation
+ MoveTowardsPlayer()
+ Shoot()

Boss

• HP: 40-100
• 3 Types
• Spread Fire
• Horizontal Movement
+ MoveHorizontally()
+ ShootSpread()

Asteroid

• Multi-Hit HP
• 4 Types
• Rotation
• Death Animation

Buff Pickup

• 5 Types
• Float Animation
• Color Pulse
• 15s Duration

Laser

• Player/Enemy
• Velocity
• Off-screen Removal

?? Controls

Keyboard

• WASD: Movement
• Space: Shoot
• Enter: Confirm
• Escape: Back
• L: Leaderboard
• F11: Fullscreen

Mouse

• Left Click: Shoot
• Click Buttons: Navigate
• Hover: Highlight

GamePad

• Left Stick: Movement
• A Button: Shoot/Confirm
• B Button: Back
• Back Button: Exit
